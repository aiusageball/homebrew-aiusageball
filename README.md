# Homebrew tap for AI Usage Ball

Install the signed Apple Silicon build:

```bash
brew tap aiusageball/aiusageball
brew install --cask ai-usage-ball
```

Requires macOS 12+ (Monterey) on Apple Silicon.

Source / releases: https://github.com/aiusageball/ai-usage-ball  
Site: https://aiusageball.com
